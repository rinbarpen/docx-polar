# 权利要求书撰写指南

权利要求书是专利文件的核心，直接决定专利保护范围的大小。写得过宽可能被驳回，写得过窄则保护力度不足。

---

## 基本结构

### 独立权利要求（必须有，至少1条）

用于概括发明的核心技术方案，保护范围最宽。结构分为两部分：

```
[序号]. 一种[主题名称]，[前序部分，现有技术中已知的特征]，
其特征在于，[特征部分，本发明区别于现有技术的必要技术特征]。
```

**前序部分**（前序部分）：
- 说明主题类型（"一种装置"、"一种方法"、"一种系统"）
- 列出本发明所属现有技术中已有的技术特征（为发明奠定技术背景）
- 如果发明是全新的，前序部分可以只写主题名称

**特征部分**（以"其特征在于"引导）：
- 只包含区别于现有技术的必要技术特征
- 必要 = 缺少任何一个，就无法解决技术问题
- 不必要的特征不写进独立权利要求（留给从属权利要求）

### 从属权利要求（建议5–10条）

在独立权利要求基础上进一步限定，提供梯度保护。结构：

```
[序号]. 根据权利要求[X]所述的[主题名称]，其特征在于，[附加或进一步限定的特征]。
```

## 示例

### 发明专利（方法类）

```
1. 一种基于深度学习的焊缝缺陷检测方法，其特征在于，包括以下步骤：
   采集焊接过程中的实时图像；
   将所述图像输入预训练的YOLOv8卷积神经网络模型，对图像中的缺陷区域进行定位和分类；
   根据分类结果生成缺陷报告，所述缺陷类型包括气孔、裂纹和未熔合。

2. 根据权利要求1所述的方法，其特征在于，所述YOLOv8模型通过包含10000张以上
   标注焊缝图像的数据集进行微调训练。

3. 根据权利要求1所述的方法，其特征在于，所述采集步骤使用分辨率不低于
   500万像素的工业相机，帧率不低于30fps。

4. 根据权利要求1所述的方法，其特征在于，还包括：
   当检测到缺陷面积超过预设阈值时，触发报警信号并暂停焊接设备。
```

### 实用新型专利（产品结构类）

```
1. 一种折叠式充电宝支架，其特征在于，包括：
   底座，其上设有旋转轴；
   支撑臂，通过所述旋转轴与底座转动连接，可在0°至120°范围内调节角度；
   托盘，固定于所述支撑臂顶端，用于放置充电宝；
   所述托盘底部设有多个通孔构成的散热槽。

2. 根据权利要求1所述的折叠式充电宝支架，其特征在于，
   所述旋转轴上设有阻尼结构，使支撑臂能在任意角度保持固定。

3. 根据权利要求1所述的折叠式充电宝支架，其特征在于，
   所述底座底面设有防滑硅胶垫。
```

## 权利要求层次策略（保护梯度）

好的权利要求布局应当形成"由宽到窄"的梯度，即使独立权利要求被无效，从属权利要求仍能提供保护：

```
独立权利要求（最宽，覆盖所有变体）
  └── 从属权利要求1（中等范围，限定主要实施方式）
        └── 从属权利要求2（较窄，限定最优实施例）
  └── 从属权利要求3（另一技术方向的限定）
  └── 从属权利要求4（特定参数/材料的限定）
```

---

## 多项从属权利要求规则

从属权利要求可以引用多个前项权利要求（用"或"连接），但有限制：

```
✅ 合法：
5. 根据权利要求2或3所述的装置，其特征在于……

❌ 不合法：
6. 根据权利要求4或5所述的装置，其特征在于……
   （权利要求4或5本身已经是多项从属权利要求，不能作为多项从属的基础）
```

---

## 5个常见错误

1. **独立权利要求包含非必要特征**：将具体实施细节写入独立权利要求，导致保护范围过窄。
   - 错误：`…其特征在于，所述传感器为型号XYZ-100的温度传感器…`
   - 正确：`…其特征在于，包括温度传感器…`（型号放到从属权利要求）

2. **权利要求中出现说明书没有支持的特征**：权利要求保护范围超出说明书记载的范围，会被驳回。

3. **实用新型写方法权利要求**：实用新型只保护产品形状/构造，不能保护方法步骤。

4. **前序部分写了发明的核心区别特征**：区别特征误放到前序，导致自己否定了新颖性。

5. **从属权利要求编号顺序错误**：如权利要求3引用了权利要求5（引用后项），这是不允许的。

---

## 实用新型 vs 发明专利权利要求的区别

| 方面 | 发明专利 | 实用新型专利 |
|-----|---------|------------|
| 可保护的主题 | 产品、方法、用途 | 仅产品（形状/构造） |
| 方法权利要求 | ✅ 允许 | ❌ 不允许 |
| 独立权利要求数量 | 通常1–3条 | 通常1–2条 |
| 保护范围要求 | 有实质性创造 | 有实质性特点和进步即可 |

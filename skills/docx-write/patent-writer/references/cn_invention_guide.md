# 发明专利撰写指南

发明专利是三类专利中保护范围最广、审查最严格的类型，保护期20年。既可保护产品，也可保护方法、工艺和用途。

---

## 文件组成

| 文件 | 要求 |
|-----|-----|
| 请求书 | 填写申请人信息（正式申请时提交，草稿阶段可略） |
| 说明书 | 必须，详见下文 |
| 权利要求书 | 必须，参见 claims_guide.md |
| 说明书摘要 | 必须，150-300字 |
| 说明书附图 | 可选，但强烈建议提供 |
| 摘要附图 | 如有附图则必须指定一张 |

---

## 说明书各部分详细要求

### 1. 技术领域（技术领域）

**目的**：快速定位专利所属的技术分支。

**写法**：
- 使用一到两句话，指向最具体的技术分支（不要写得太宽泛）
- 模板：`本发明涉及[具体技术领域]，尤其涉及一种[更具体的技术方向]。`

**字数**：50–150字

**示例**：
> 本发明涉及计算机视觉与工业检测领域，尤其涉及一种基于深度卷积神经网络的焊缝表面缺陷实时检测方法及系统。

**常见错误**：
- ❌ "本发明涉及人工智能领域"（太宽泛）
- ✅ "本发明涉及工业图像处理领域，尤其涉及焊接质量检测"

---

### 2. 背景技术（背景技术）

**目的**：说明现有技术的状况及其缺陷，为本发明的必要性提供论据。

**写法**：
1. 描述与本发明最接近的现有技术方案（引用对比文件）
2. 分析其存在的具体缺陷（过多、过少、精度不足、成本高等）
3. 确保指出的缺陷是本发明要解决的问题

**字数**：300–800字

**引用格式**：
> 现有技术中，如中国专利公开号CN XXXXXXXX A所公开的……该方案虽然……，但仍存在以下不足：（1）……；（2）……

**注意事项**：
- 必须客观，不可过度贬低现有技术
- 引用的现有技术缺陷要与本发明解决的问题直接对应
- 不引用自己的专利或产品（避免不必要的信息披露）

---

### 3. 发明内容（发明内容）

**目的**：简述本发明"是什么"及"为什么好"，起承上启下的作用。

**固定三段结构**：

```
第一段（技术问题）：
  本发明的目的在于克服上述现有技术的不足，提供一种……，以解决……的问题。

第二段（技术方案）：
  为实现上述目的，本发明采用如下技术方案：
  [简述独立权利要求的核心内容，语言可稍作变通但不能超出权利要求范围]

第三段（有益效果）：
  与现有技术相比，本发明的有益效果在于：
  （1）……；（2）……；（3）……
```

**字数**：400–1000字

**注意**：技术方案部分的内容必须与权利要求书一致，不得写出权利要求书没有的保护内容。

---

### 4. 附图说明（附图说明）

**目的**：逐一说明每张附图所展示的内容。

**格式**：
```
图1为本发明实施例中[设备/系统]的整体结构示意图；
图2为本发明实施例中[某模块]的详细结构示意图；
图3为本发明实施例中[方法]的流程图。
```

**字数**：每张图一句话，通常50–200字合计

**要求**：
- 图号从图1开始连续编号
- 说明要精简，只说"是什么"，不说"怎么运行"

---

### 5. 具体实施方式（具体实施方式）

**目的**：让本领域技术人员能够依据说明书重现发明，是最详细的部分。

**写法**：
- 以"实施例一"、"实施例二"等编号
- 结合附图编号（"如图1所示"），逐一描述每个技术特征
- 每个权利要求中的特征都要在这里找到详细对应描述
- 方法类发明：逐步骤描述，说明每步的输入、处理过程、输出
- 产品类发明：描述各部件的结构、材质、尺寸范围、连接方式和功能

**字数**：1500–5000字（视发明复杂程度）

**至少提供2个实施例**，例如：
- 实施例一：基础实现
- 实施例二：优化实现（引入某优化特征）
- 实施例三（可选）：另一应用场景

**示例段落**：
> 如图1所示，本发明一种实施例中，焊缝缺陷检测系统100包括图像采集模块10、预处理模块20、深度学习推理模块30和报警输出模块40。
>
> 图像采集模块10采用工业线扫相机，分辨率不低于500万像素，安装于焊接头前方150mm处，以30fps的帧率持续采集焊缝区域的彩色图像……

## 发明专利特别注意事项

### 充分公开原则
说明书必须对发明作出清楚、完整的说明，以所属技术领域技术人员能够实现为准。如果说明书缺少关键步骤或参数，权利要求将因"缺乏支持"被驳回。

### 创造性要求
发明专利要求"非显而易见性"——不仅要新颖，还要与现有技术相比有实质性的技术进步。在"发明内容"和"具体实施方式"中应清楚体现技术进步的原因（不只是"效果更好"，而是"为什么效果更好"）。

### 功能性限定的使用
权利要求中可以使用功能性语言（"用于…的装置"），但必须在说明书中提供足够的具体实施方式支持，否则保护范围可能被限制为说明书中公开的具体实施方式。

## 字数参考（完整说明书）

| 部分 | 建议字数 |
|-----|--------|
| 技术领域 | 50–150字 |
| 背景技术 | 300–800字 |
| 发明内容 | 400–1000字 |
| 附图说明 | 50–200字 |
| 具体实施方式 | 1500–5000字 |
| **合计** | **~2500–7000字** |

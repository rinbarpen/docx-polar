# 外观设计专利撰写指南

外观设计专利保护产品的美学外观（形状、图案、色彩或其组合），不保护功能性技术方案。审查简单，授权快（6–8个月），保护期15年。

---

## 基本概念

| 要素 | 说明 |
|-----|-----|
| **保护对象** | 产品整体或局部的外观（形状+图案+色彩的组合） |
| **新颖性要求** | 与已有外观设计明显不同或有明显区别 |
| **审查方式** | 形式审查（不审查实质内容） |
| **申请文件** | 仅需：请求书 + 图片/照片 + 简要说明（无需说明书和权利要求书） |

---

## 文件组成

外观设计专利**不需要**说明书和权利要求书，只需：

1. **图片或照片**（核心文件）
2. **简要说明**
3. 请求书（正式申请时填写）

---

## 图片/照片要求

### 必须提供的视图（六视图）

| 视图 | 英文名 | 拍摄/绘制方向 |
|-----|--------|-------------|
| 正视图 | Front view | 正面朝向 |
| 后视图 | Rear view | 背面朝向 |
| 左视图 | Left side view | 左侧面 |
| 右视图 | Right side view | 右侧面 |
| 俯视图 | Top view | 顶部向下 |
| 仰视图 | Bottom view | 底部向上 |

**可选补充视图**：
- 立体图（效果图）：最直观，强烈建议提供
- 局部放大图：对有特殊细节的区域
- 展开图：适用于折叠类产品
- 截面图：适用于有复杂内部结构影响外观的产品

### 图片质量要求

- **分辨率**：300 DPI 以上（用于正式申请时打印清晰）
- **背景**：白色或浅色单色背景，不能有阴影干扰
- **比例**：所有视图应保持一致比例
- **格式**：PNG 或 TIFF（官网提交支持的格式）
- 同一产品的所有视图**风格必须统一**（不能一些是照片、一些是手绘）

### 色彩保护

- 如果请求保护特定色彩，必须提交**彩色**图片
- 如果只保护形状/图案，黑白图片即可
- 在简要说明中写明："本外观设计请求保护色彩"

---

## 简要说明撰写

简要说明是外观设计专利仅有的文字文件，格式相对固定：

### 固定格式

```
一、本外观设计产品的用途：
[产品的具体用途，一句话说明]

二、本外观设计的设计要点：
[外观设计的创新点在哪里——形状？图案？色彩？局部特征？]

三、指定图片或照片：
[指定哪一张图作为最能代表本设计要点的主视图]
```

### 示例

```
一、本外观设计产品的用途：
本外观设计用于蓝牙音箱，供播放音频使用。

二、本外观设计的设计要点：
本外观设计的设计要点在于产品的整体形状，
尤其是正面及侧面的几何切面造型和多边形拼接图案。

三、指定图片或照片：
指定立体图为最能表明本外观设计设计要点的图片。
```

### 注意事项

简要说明中**不得包含**：
- 功能性说明（"本产品具有降噪功能"）
- 技术特征说明（"外壳材料为铝合金"）
- 商业宣传语（"美观大方，深受消费者喜爱"）
- 专利术语（"其特征在于"）

简要说明只描述外观的视觉特征，不涉及内部结构或功能。

---

## 局部外观设计

中国专利法（2021年修订后）允许对**产品的局部外观**申请外观设计专利。

申请局部外观设计时：
- 在图片中用虚线/实线区分：**实线**表示请求保护的局部，**虚线**表示参考的整体外观
- 在简要说明中注明："本外观设计请求保护产品局部外观，图中实线部分为请求保护的设计内容。"

---

## 设计要点常见表述

根据设计特点，选择合适的描述角度：

| 设计创新点 | 简要说明表述示例 |
|----------|--------------|
| 整体造型 | "设计要点在于产品的整体形状，尤其是……" |
| 正面图案 | "设计要点在于产品正面的图案设计，包括……" |
| 色彩搭配 | "设计要点在于产品的色彩及图案的组合，即……" |
| 局部特征 | "设计要点在于产品[具体部位]的形状，尤其是……" |
| 多视角结合 | "设计要点在于产品正面和侧面的组合造型，包括……" |

---

## 外观设计不适用的情况

以下情况无法通过外观设计专利保护：
- 纯平面作品（如画作、图形）——适合著作权保护
- 功能性形状（外形完全由功能决定，如螺旋桨叶片形状）
- 软件界面中的纯色彩方案（无特定图案）
- 包装盒内部结构（用户无法看到的部分通常不受保护）
